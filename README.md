# 홀덤 스터디룸

친구들과 배우는 한국어 텍사스 홀덤 교육 사이트입니다. 설치·로그인·외부 API 없이 실행되는 단일 HTML입니다.

공개 사이트: [홀덤 스터디룸](https://koduckfeel.github.io/holdem-study-room/)

- 처음 배우기: 카드와 코인 그림으로 보는 네 단계 입문 안내
- 족보 구성 카드만 빨간 선으로 묶은 족보표와 용어 사전 50개
- 콜 가격 설명과 코인 계산기
- 프리플랍·플랍 10문제 연습, 총평과 다른 행동 비교
- 실제 칩 100·500·1,000·5,000·10,000코인으로 보는 가격 설명
- 공식·전문 교육·원논문 읽을거리 12개와 선택적으로 펼치는 평가 안내

친구 룰은 전원 100코인 참가비, 별도 블라인드 없음입니다. 시작 스택은 20,000코인이고 베팅·콜·레이즈는 500코인 단위로 연습합니다. 첫 베팅 예시는 1,500코인입니다. 참가비가 들어간 팟은 500코인 배수가 아닐 수 있습니다. 표준 홀덤 연습도 선택할 수 있습니다.

## 실행과 게시

`index.html`을 브라우저로 열거나 저장소의 GitHub Pages 주소에 접속합니다. GitHub Pages 설정은 `main` 브랜치의 `/(root)`를 사용합니다. `.nojekyll`은 정적 파일을 그대로 게시하게 합니다.

사이트 수정 후 `index.html`을 교체해 `main`에 커밋하면 Pages가 다시 게시합니다. 별도 패키지 설치나 빌드 명령은 필요 없습니다.

## 평가의 범위

프리플랍은 공개한 교육용 시작 패 표를 사용합니다. 플랍의 수치는 상대 한 명, 지금 콜한 뒤 추가 베팅 없이 끝까지 공개하는 조건부 모델입니다. 실제 상대의 승률이나 실전 GTO 정답을 보장하지 않습니다. 자세한 가정과 논문은 해설과 외부 자료의 보조 링크인 ‘연습 평가 안내’에서 필요한 부분만 펼쳐볼 수 있습니다.

진행 설정과 출제 기록은 각자의 브라우저에 저장됩니다. 실제 돈·결제·온라인 포커 게임 연동은 없습니다.
